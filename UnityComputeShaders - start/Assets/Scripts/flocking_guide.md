# 플로킹(Flocking) 알고리즘 완벽 정리

## 플로킹이란?

물고기 떼, 새 떼가 움직이는 원리를 구현한 알고리즘입니다.
단 3가지 규칙만으로 자연스러운 무리 행동이 만들어집니다.

```
1. Separation (분리) - 너무 가까우면 피해!
2. Alignment (정렬) - 같은 방향으로 가자!
3. Cohesion (응집) - 무리 중심으로 모이자!
```

---

## 규칙 1: Separation (분리)

### 개념
```
"너무 가까이 오지 마!"

    🐟 ← 나
   ↗ 
  🐟 ← 얘가 너무 가까워!
  
→ 반대 방향으로 밀어내는 힘 발생
```

### 코드
```hlsl
float3 offset = boid.position - tempBoid_position;
// 나 - 상대 = 상대에서 나를 향하는 방향

separation += offset * (1.0/dist - 1.0/neighbourDistance);
```

### 공식 해석: `(1.0/dist - 1.0/neighbourDistance)`

| dist (거리) | 계산 | 결과 | 의미 |
|-------------|------|------|------|
| 2 (매우 가까움) | 1/2 - 1/10 | 0.4 | 강하게 밀어냄! |
| 8 (좀 멀어짐) | 1/8 - 1/10 | 0.025 | 살짝만 밀어냄 |
| 10 (경계) | 1/10 - 1/10 | 0 | 안 밀어냄 |

**핵심: 가까울수록 더 세게 밀어낸다!**

---

## 규칙 2: Alignment (정렬)

### 개념
```
"다들 어디로 가? 나도 그쪽으로 갈게!"

  🐟→  🐟→  🐟→
       ↑
      🐟 (나) "다들 오른쪽으로 가네? 나도!"
       ↓
       →
```

### 코드
```hlsl
// 주변 물고기들의 방향을 다 더함
alignment += boidsBuffer[i].direction;

// 나중에 평균 냄
alignment *= avg;
```

### 예시
```
주변 물고기 3마리의 방향:
물고기 A: (1, 0, 0)    → 오른쪽
물고기 B: (1, 0.5, 0)  → 오른쪽 + 약간 위
물고기 C: (1, -0.3, 0) → 오른쪽 + 약간 아래

합계: (3, 0.2, 0)
평균: (1, 0.067, 0) → 대충 오른쪽!

→ 나도 오른쪽으로 가야지
```

**핵심: 주변 물고기들의 평균 방향을 따라간다!**

---

## 규칙 3: Cohesion (응집)

### 개념
```
"무리 중심으로 모이자!"

  🐟     🐟
      ●  ← 무리 중심
  🐟  ↑
      🐟 (나) "중심 쪽으로 가야지"
```

### 코드
```hlsl
// 주변 물고기들의 위치를 다 더함
cohesion += tempBoid_position;

// 평균 위치 = 무리의 중심!
cohesion *= avg;

// 중심 - 내 위치 = 중심을 향하는 방향
// normalize = 길이를 1로 만들어 방향만 남김
cohesion = normalize(cohesion - boid_pos);
```

### 예시
```
주변 물고기 위치:
물고기 A: (5, 0, 0)
물고기 B: (3, 2, 0)
물고기 C: (4, 1, 0)

평균 (중심): (4, 1, 0)
내 위치: (2, 0, 0)

중심 - 나 = (4, 1, 0) - (2, 0, 0) = (2, 1, 0)
normalize → 방향만! → "오른쪽 위로 가!"
```

**핵심: 무리의 중심 방향으로 이동한다!**

---

## 3가지 규칙 합치기

```hlsl
float3 direction = alignment + separation + cohesion;
```

```
최종 방향 = 정렬 + 분리 + 응집

      정렬: → (다들 오른쪽으로 가네)
    + 분리: ↑ (왼쪽 녀석 피해야지)
    + 응집: ↗ (중심 쪽으로)
    ─────────
    = 최종: ↗→ (오른쪽 위!)
```

---

## 부드러운 방향 전환

### 개념
갑자기 방향 바꾸면 부자연스러우니까 현재 방향 ↔ 새 방향 사이를 부드럽게 섞습니다.

### 코드
```hlsl
float ip = exp(-rotationSpeed * deltaTime);
boid.direction = lerp(direction, normalize(boid_dir), ip);
```

### 해석
```
ip가 크면 (1에 가까움): 현재 방향 유지 → 천천히 회전
ip가 작으면 (0에 가까움): 새 방향으로 빨리 전환

exp(-rotationSpeed * deltaTime):
- rotationSpeed가 크면 → ip가 작아짐 → 빨리 회전
- rotationSpeed가 작으면 → ip가 커짐 → 천천히 회전
```

## 최종 이동

```hlsl
boid.position += (boid.direction) * (velocity * deltaTime);
```

```
새 위치 = 현재 위치 + 방향 × 속도 × 시간

- 방향: 어디로 갈지 (위에서 계산한 direction)
- velocity: 얼마나 빨리 (물고기마다 다를 수 있음)
- deltaTime: 프레임 간 시간 (일정한 속도 유지용)
```

---

## 전체 흐름 요약

```
1. 주변 물고기들을 찾는다 (neighbourDistance 범위 내)

2. 3가지 힘 계산:
   - Separation: 가까운 물고기를 피하는 방향
   - Alignment: 주변 물고기들의 평균 방향
   - Cohesion: 무리 중심을 향하는 방향

3. 3가지 힘을 합쳐서 최종 방향 결정

4. 현재 방향 → 최종 방향으로 부드럽게 전환

5. 새 방향으로 이동!

6. 모든 물고기가 동시에 이 과정을 수행 (GPU 병렬처리)
```

---

## 변수 설명

| 변수 | 의미 | 조절 효과 |
|------|------|----------|
| `neighbourDistance` | 주변 인식 범위 | 크면 더 넓은 범위의 물고기 인식 |
| `rotationSpeed` | 회전 속도 | 크면 방향 전환이 빨라짐 |
| `boidSpeed` | 기본 이동 속도 | 크면 빨리 이동 |
| `boidSpeedVariation` | 속도 변화량 | 크면 물고기마다 속도 차이 커짐 |
| `noise_offset` | 개별 물고기 고유값 | 물고기마다 다른 움직임 부여 |

---

## 비유로 최종 정리

```
플로킹 = 학교에서 반 친구들과 이동하는 것

Separation (분리):
"야, 너무 붙지 마!" → 친구가 너무 가까우면 살짝 비켜줌

Alignment (정렬):
"다들 어디 가?" → 친구들이 가는 방향 보고 따라감

Cohesion (응집):
"같이 가자~" → 무리에서 떨어지지 않게 중심으로 모임

이 3가지가 동시에 일어나면
→ 자연스러운 무리 이동!
```
